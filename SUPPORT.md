# Support

## Documentation first

Use the docs site first:

- <https://rigu.github.io/vps-coolify-bootstrap/>

## How to ask for help

Open a GitHub issue with:

- environment details (provider, Ubuntu version)
- exact command run
- sanitized logs/error output
- expected vs actual behavior

Do not include secrets, private keys, real credentials, or private hostnames.

## Security issues

For vulnerabilities, use private reporting:
