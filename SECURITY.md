# Security Policy

## Supported versions

Security fixes are applied on the `main` branch.

## Reporting a vulnerability

Please do **not** open a public issue for undisclosed vulnerabilities.

Report privately via GitHub Security Advisories:

- `Security` tab -> `Report a vulnerability`

Include:

- affected file/path
- reproduction steps
- impact assessment
- mitigation suggestion (if available)

## Response targets

- Initial acknowledgment: within 3 business days
- Triage/update: within 7 business days

## Operational note

This repository provides bootstrap templates/scripts, not managed hosting.
End users are responsible for production hardening and operational controls.
